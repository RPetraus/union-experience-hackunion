# Union Navigator

A mobile-first campus map for HackUnion 2026 that helps Union College students quickly find food, wellness resources, safety support, study spaces, events, and extracurriculars.

## Problem

Union students often have to search across multiple pages, emails, and campus systems to answer simple questions like:

- Where can I eat right now?
- Where can I study?
- Where do I go if I need physical or mental health support?
- What events or club meetings are happening?

## Solution

Union Navigator puts campus resources on one interactive map with category filters, search, and clickable location cards.

## Features

- Interactive Union College map
- Category filters: Hungry, Physical Health, Mental Health, Safety, Study, Events, Extracurriculars
- Search bar
- Clickable map points
- Resource details with hours, descriptions, and links
- Mobile-first responsive layout

## Tech Stack

- React
- Vite
- Leaflet
- React Leaflet
- OpenStreetMap
